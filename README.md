# MANVIA Hub

Build a complete, modern, premium, responsive fitness and wellness website called:

MANVIA

Tagline:

"Move Better. Feel Stronger. Live Better."

The website must look like a professional commercial fitness and wellness brand, NOT like a basic college project.

The website should be created ONLY using:

- HTML5

- CSS3

- Vanilla JavaScript

- Chart.js via CDN where charts are required

- Font Awesome or Lucide icons via CDN

- Google Fonts

Do NOT use React, Next.js, TypeScript, Tailwind CSS, Bootstrap, or any frontend framework.

The website must contain exactly 7 main pages.
